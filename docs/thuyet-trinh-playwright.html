Định nghĩa

Playwright là gì?

Playwright là framework mã nguồn mở do Microsoft phát triển, dùng để tự động hóa trình duyệt và kiểm thử ứng dụng web hiện đại.

Viết một bộ mã, chạy trên ba engine:

Chromium

Nền tảng của Chrome và Edge. Sport Shop đang chạy trên engine này.

Firefox

Engine độc lập, dùng khi cần kiểm tra tương thích Mozilla.

WebKit

Engine của Safari, dùng khi cần kiểm tra trên hệ sinh thái Apple.

Playwright Test (TypeScript) có sẵn test runner, assertion, chạy song song, HTML Report và Trace Viewer. Bộ Sport Shop dùng API Python playwright.sync_api vì cần đọc/ghi Excel và gọi fixture PHP.

Quy trình

Nguyên lý hoạt động

1. Khởi động browser→ 2. BrowserContext→ 3. Mở trang→ 4. Locator→ 5. Thao tác→ 6. So sánh→ 7. Pass / Fail→ 8. Báo cáo

BrowserContext = một phiên trình duyệt riêng

Cookie, tài khoản đăng nhập và dữ liệu giữa các phiên không ảnh hưởng lẫn nhau. Sport Shop tạo 3 context cùng lúc: guest (chưa login), user (khách hàng), admin (quản trị).

browser = p.chromium.launch(headless=HEADLESS)
guest_ctx = browser.new_context(locale="vi-VN", viewport={"width": 1366, "height": 768})
user_ctx  = browser.new_context(locale="vi-VN", viewport={"width": 1366, "height": 768})
admin_ctx = browser.new_context(locale="vi-VN", viewport={"width": 1366, "height": 768})

Auto-waiting

Tự chờ trước khi thao tác

Trước khi nhấn nút, Playwright kiểm tra phần tử: tồn tại, hiển thị, được bật, ổn định, nhận sự kiện chuột.

Người viết test ít phải dùng waitForTimeout() thủ công — hạn chế test lúc Pass lúc Fail.

def login_admin(page, username, password):
    goto(page, "admin-auth/login")
    page.wait_for_selector("#adminUsername")   # chờ ô nhập hiện
    page.fill("#adminUsername", username)
    page.fill("#adminPassword", password)
    page.click("button.admin-login-submit")    # click khi nút sẵn sàng
    return "admin-dashboard" in page.url

File: tests/e2e/pw_common.py. Lệnh wait_for_timeout(400) chỉ dùng thêm sau khi trang tải xong, không thay thế auto-waiting.

Codegen

Ghi thao tác và sinh mã

npx playwright codegen http://localhost/SportShop

Sau khi chạy lệnh, thao tác trực tiếp trên website. Playwright tạo click(), fill() và assertion tương ứng.

Lưu ý khi thuyết trình

Mã Codegen chỉ là bản nháp. Bộ Sport Shop không chạy nguyên mã sinh ra, mà chuẩn hóa thành helper: goto, login_admin, confirm, SheetRun.check — để 64 case dùng chung một cách viết.

Ngôn ngữ

Playwright hỗ trợ nhiều ngôn ngữ

  • JavaScript
  • TypeScript — thuận tiện nhất với Playwright Test
  • Python — lựa chọn của Sport Shop
  • Java + JUnit / TestNG
  • .NET / C#

Vì sao bài này dùng Python?

Website viết PHP MVC, không phải Spring Boot. Bộ test cần:

  • Đọc Excel gốc bằng openpyxl
  • Gọi fixture PHP để tạo user/sản phẩm
  • Ghi Pass/Fail đúng từng dòng Excel

Python gắn được Playwright, Excel và subprocess PHP trong một thư mục tests/e2e/, không trộn vào mã nguồn cửa hàng.

Thư viện: playwright==1.55.0 và openpyxl==3.1.5.

Ví dụ code

Phân quyền ADMIN và USER

Case 1–3 sheet người dùng: khách chưa login và tài khoản USER không được vào trang quản trị.

goto(guest, "admin-user/index")
s.check(1, "admin-auth/login" in guest.url, f"url={guest.url}", page=guest)

login_user(user, info["customer"]["username"], info["customer"]["password"])
goto(user, "admin-user/index")
s.check(2, "admin-auth/login" in user.url, f"url={user.url}", page=user)

goto(admin, "admin-user/index")
s.check(3, has(admin, "Người dùng") and admin.locator("input[name=q]").count(),
        f"url={admin.url}")

Ba thao tác chạy trên ba Page khác nhau. Cookie ADMIN không lẫn cookie USER — đúng nguyên lý BrowserContext.

HTTP / CSRF

code = status_of(admin, "POST", "admin-user/index", form={"a": "1"})

fetch(admin, "POST", f"admin-user/edit/{fid}",

Playwright vừa điều khiển UI vừa gửi request (page.request.fetch) để kiểm tra method sai, CSRF giả, upload ảnh — không cần Postman riêng.

Cách chạy bộ test

Yêu cầu: Apache + MySQL XAMPP đang bật, website tại http://localhost/SportShop.

$env:PYTHONIOENCODING = "utf-8"
$py = "C:\Users\ADMIN\AppData\Local\Programs\Python\Python312\python.exe"
cd c:\xampp\htdocs\SportShop
& $py tests\e2e\playwright_qlcuahang.py

# Hiện cửa sổ trình duyệt khi demo:
$env:SPORTSHOP_HEADLESS = "0"

Chế độ mặc định là headless (chạy nền). Khi thuyết trình, bật SPORTSHOP_HEADLESS=0 để giám khảo thấy Chromium tự đăng nhập, tìm kiếm, khóa tài khoản.

Tóm tắt

Kết luận

  • Playwright tự động hóa trình duyệt trên Chromium, Firefox, WebKit; giấy phép Apache 2.0.
  • Phù hợp kiểm thử E2E: đăng nhập, CRUD, form, phân quyền, API, ảnh chụp, CI/CD.
  • BrowserContext tách phiên; auto-waiting giảm test flaky; Locator thao tác giống người dùng.
  • Sport Shop đặt bộ Python riêng trong tests/e2e/, đọc Excel 274 case, xuất kết quả và screenshot.
  • Đã gắn với chức năng thật: admin login, người dùng, sản phẩm, đánh giá, dashboard, QR.

Tài liệu tham khảo: Playwright docs (Intro, Authentication, Auto-waiting, Codegen) · kho Microsoft Playwright · mã nguồn tests/e2e/.
